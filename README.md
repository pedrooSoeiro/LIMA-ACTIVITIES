# 📥 Como Baixar/Clonar Repositórios do GitHub

Aprenda a baixar repositórios do GitHub para o seu computador de forma rápida e simples.

---

## 🛠️ Método 1: Usando o Git (Recomendado)

Esta é a melhor opção se você já tem o **Git instalado** e quer manter o projeto conectado com o GitHub para enviar alterações depois.

### Passo a Passo:

1. Acesse a página do repositório no [GitHub](https://github.com).
2. Clique no botão verde **`<> Code`**.
3. Na aba **HTTPS**, copie o link exibido (exemplo: `https://github.com/seu-usuario/seu-repositorio.git`).
4. Abra o seu terminal (Terminal, Git Bash ou Prompt de Comando).
